# إضافة مدار لتعبئة بيانات التقديم

إضافة اختيارية لـ **Chrome أو Edge على الكمبيوتر**. لا تعمل هذه الإضافة على Safari في iPhone أو Chrome في Android؛ استخدم نسخ البيانات ومشاركة/تنزيل السيرة من مدار على الجوال.

## التثبيت والاستخدام

1. نزّل إضافة التعبئة من صفحة الفرص في مدار وفكّ ملف ZIP في مجلد مستقل. يجب أن يكون `manifest.json` داخل المجلد الذي ستختاره.
2. في Chrome افتح `chrome://extensions`، أو في Edge افتح `edge://extensions`، وفعّل **وضع المطوّر**.
3. اختر **تحميل إضافة تم فك حزمتها / Load unpacked** وحدد المجلد الذي يحتوي على `manifest.json`.
4. افتح **الفرص والتقديم** في مدار، وحدّث ملفك الشخصي والسيرة، ثم نزّل **بيانات التقديم للإضافة**. هذا الملف يتضمن البيانات الشخصية وسيرة PDF المرفقة؛ احفظه على جهازك الخاص.
5. افتح الإضافة من شريط المتصفح، واستورد ملف JSON. تظل البيانات محفوظة محلياً في الإضافة حتى تختار **حذف البيانات من الإضافة** أو تحذف الإضافة. لا تُضمّن بيانات شخصية في ملفات الإضافة نفسها.
6. افتح موقع الوظيفة أو الدورة بنفسك، وسجّل الدخول بنفسك عند الحاجة. انتقل إلى نموذج التقديم، ثم افتح الإضافة واضغط **تعبئة الصفحة الحالية**.
7. راجع كل الحقول والملف المرفق في الموقع، وأكمل الحقول المتبقية والموافقات بنفسك ثم أرسل بنفسك. احذف ملف JSON من الجهاز عند الاستغناء عنه.

لا تطلب الإضافة أذونات دائمة لكل المواقع. الأذونات الوحيدة: `activeTab` و`scripting` للتعبئة بعد الضغط على زر الإضافة في التبويب الحالي، و`storage` لحفظ البيانات المستوردة محلياً. لا توجد طلبات شبكة أو خوادم أو تحليلات في الإضافة.

## ما الذي تعبّئه؟

تتعرف الإضافة إلى أسماء وعناوين الحقول العربية والإنجليزية الشائعة للاسم الكامل، البريد، الجوال، المدينة، النبذة، المسمى المهني، الجامعة، التخصص، سنة التخرج، التعليم، الخبرات، المهارات، لينكدإن والموقع الشخصي. تعبّئ الحقول الفارغة المرئية القابلة للتحرير فقط. القوائم تحتاج خياراً مطابقاً تماماً للقيمة المحفوظة.

تُرفق السيرة كملف **PDF فعلي لا يتجاوز ٢ ميغابايت** إذا وُجد حقل واضح للسيرة يقبل PDF وكان فارغاً. تتحقق الإضافة من نوع الملف وحجمه وترويسة PDF؛ هذا تحقق للصيغة وليس فحصاً لمحتوى الملف. تحتفظ بأي ملف أو قيمة موجودين. قد يتعامل موقع التقديم مع اختيار ملف بأنه رفع فوري؛ استخدم الزر فقط على الموقع الذي اخترته لتقديم بياناتك إليه.

لا تعبّئ الإضافة كلمات المرور، رموز التحقق، أسماء المستخدمين، الحقول المخفية أو الموافقات، ولا تضغط أزرار التقديم أو التسجيل أو الإرسال. بعض المواقع تستخدم حقولاً مخصصة أو إطارات أو عناصر لا تدعم التعبئة؛ استخدم النسخ والرفع اليدوي عندها. نتيجة الزر تصف عدد الحقول التي عُبئت وحالة السيرة؛ لا تعني إنشاء حساب أو إتمام تقديم.

## صيغة الاستيراد

```json
{
  "format": "madar-application-profile",
  "version": 1,
  "profile": {
    "fullName": "اسم تجريبي",
    "email": "student@example.test",
    "skills": ["إدارة المخزون"]
  }
}
```

يمكن إضافة حقول الملف الشخصي الاختيارية: `phone`, `city`, `headline`, `summary`, `university`, `major`, `graduationYear`, `education`, `experience`, `linkedin`, `website`. صيغة السيرة الاختيارية: `cv: {name, mime: "application/pdf", dataUrl: "data:application/pdf;base64,...", size, updatedAt}`. تستبعد الحزمة صورة البروفايل والبيانات الدراسية والمالية، ولا تحتوي كلمات مرور. حجم ملف JSON الأقصى ٣ ميغابايت. لا تستورد ملفات من مصادر غير موثوقة.

## التحقق المحلي للمطور

شغّل `python3 tests/autofill_browser.py` من جذر المستودع مع Python Playwright وChromium في `/usr/bin/chromium`. يستخدم الاختبار نموذجاً محلياً وبيانات اصطناعية، ويتحقق من التعبئة والأحداث وعدم تغيير القيم المحفوظة أو كلمات المرور أو الموافقات، وأن السيرة ملف ببايتاته الأصلية، وعدم إرسال النموذج. يختبر وحدات واجهة الإضافة الأصلية باستخدام محاكاة محلية لواجهات Chrome؛ متصفح البيئة السحابية يمنع تثبيت الإضافات غير المحزّمة بسياسة إدارية، ولذلك لا يحاول الاختبار تجاوزها ولا يثبت أن التثبيت الفعلي اختُبر في تلك البيئة.
