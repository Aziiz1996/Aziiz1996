# عزيز ليدر

نسخة ويب عربية لتنظيم الدراسة، جاهزة للتشغيل بخادم حسابات وتثبيتها من سفاري على شاشة الآيفون الرئيسية. لا توجد استضافة عامة أو نسخة iOS موقّعة حالياً.

## التشغيل

يتطلب Node.js 22.12 أو أحدث. تم البناء والفحص على Node.js 24.

```sh
npm ci
npm run build
npm start
```

الخادم المحلي يستمع افتراضياً على المنفذ 3001. للتطوير شغّل الخادم و`npm run dev` في جلستين؛ Vite يحوّل طلبات الحسابات إلى الخادم.

## الاستضافة

يتطلب التطبيق استضافة تشغّل Node.js، واتصال HTTPS، وقرصاً دائماً لقاعدة البيانات. لا تكفي استضافة الملفات الثابتة وحدها للحسابات. ضع `NODE_ENV=production` لتفعيل جلسات الدخول ذات ملفات تعريف الارتباط الآمنة. اضبط `PORT` و`LEADER_BIND_HOST` حسب الاستضافة، و`LEADER_DATA_DIR` لمسار القرص الدائم. لا تنشر مجلد البيانات أو النسخ الاحتياطية منه.

بعد توفر رابط HTTPS، افتحه في سفاري ثم مشاركة ثم إضافة إلى الشاشة الرئيسية. سيظهر باسم «عزيز ليدر» وبأيقونة البرنامج. لا يمكن تثبيت البرنامج على هاتف المستخدم من هذه البيئة مباشرة.

## الحسابات والبيانات

- التسجيل بالبريد الإلكتروني وكلمة مرور من عشرة أحرف على الأقل؛ التحقق من البريد واستعادة كلمة المرور غير مدمجين.
- تخزين كلمات المرور باستخدام scrypt وأملاح منفصلة. الجلسات محفوظة عبر ملفات تعريف ارتباط HttpOnly وSameSite، وSecure عند تشغيل الإنتاج.
- بيانات كل حساب مستقلة في SQLite، وطلبات الحفظ مرتبطة بمعرّف الحساب لتجنب حفظ بيانات حساب سابق بعد تبديل المستخدم.
- تسجيل الخروج يلغي الجلسة. الحفظ وتسجيل الدخول يتطلبان الاتصال بالخادم. لا تُخزن بيانات الحسابات الجديدة في LocalStorage.
- صفحات الدخول والإعدادات تحتوي رابط التواصل عبر سناب azaf.5، دون إرسال أي رسائل تلقائية.

## حساب صاحب التطبيق والمحاضرات الشخصية

الملفات الخمسة وملخصاتها و١٥ سؤال تدريب موجودة محلياً في `public/personal-lessons/`، ومستبعدة من Git. الخادم يسمح بفتحها فقط لحساب صاحب التطبيق؛ باقي الحسابات تبدأ دونها.

في النشر البسيط الذي لا يحتوي `LEADER_OWNER_SETUP_KEY` يصبح أول حساب مسجل هو حساب رئيسة تشغيل البرنامج تلقائياً، ثم يُغلق التفعيل. إذا كان هناك حساب واحد قديم ولم يوجد مالك، تُفعّل ملكيته عند دخوله الصحيح. للنشر الذي يحتاج رمزاً خاصاً، جهّز قيمة سرية طويلة وعشوائية لـ `LEADER_OWNER_SETUP_KEY` في إعدادات الخادم واستخدمها عند إنشاء حساب المالك. لا تضع الرمز في الكود أو المحادثة.

في صفحة ملخصات المواد يمكن فتح الأصول وإضافة المحاضرات إلى الملاحظات دون تكرار أو استبدال الملاحظات القائمة. الأسئلة أُعدّت من المحتوى وليست اختبارات الجامعة الرسمية. بعض النص المستخرج من PDF مشوّه بسبب خطوط الملفات.

## الخدمات الحالية

تنظيم المواد والمحاضرات والمهام والاختبارات، خطة مذاكرة، ملخصات، تدريب مع تصحيح، مجموعات مشاريع بسعة تسعة أعضاء، ودليل عشرة مواقع للتوظيف والدورات والشهادات وإكمال الدراسة.

روابط الجامعة ومودل وTeams تفتح مواقع خارجية فقط. لم يكتمل تسجيل الدخول التلقائي إلى مودل أو جلب بياناته، ولم يتم تأكيد تبعية النطاق الذي أرسله المستخدم. دليل الفرص ثابت ولا يجلب إعلانات حالية أو يضمن قبول الدبلوم في التجسير.

المساعد الحالي يبحث في البيانات المحفوظة ولا يتصل بخدمة ذكاء اصطناعي. الصوت والتذكيرات الأصلية موجودة بمشروع iOS وتحتاج البناء والاختبار على الجهاز؛ غير مفعلة في نسخة المتصفح. مشروع iOS يحتاج أيضاً عنوان خادم الحسابات قبل استخدام تسجيل الدخول الأصلي.

## التشغيل دون اتصال

تُخزن ملفات واجهة التطبيق العامة فقط لإظهار الشاشة الأساسية عند انقطاع الشبكة. الحسابات والمحاضرات الخاصة تحتاج الإنترنت ولا تدخل ذاكرة التخزين المشتركة. ملفات PDF لا تُخزن تلقائياً.

## التحقق

```sh
npm test
npm run test:accounts
npm run build
```

تم فحص فصل الحسابات، الجلسات، رفض الحفظ عبر حساب آخر أو مصدر خارجي، منع الوصول لملفات المالك، وتخزين كلمات المرور المشتقة. فحص المتصفح تحقق من التسجيل وحفظ الملاحظات بعد إعادة التحميل والخروج ورابط سناب وبيانات تثبيت التطبيق. الاختبارات استخدمت حسابات وبيانات اصطناعية.

لم يتم نشر التطبيق أو اختباره على سفاري في آيفون فعلي. النسخ القديمة من ZIP قبل إضافة الحسابات لا تمثل النسخة الحالية.
