# مدار

تطبيق عربي لتنظيم دراسة دبلوم اللوجستيات والحياة المالية، بواجهة للهاتف والحاسوب. «خطوة اليوم تصنع غداً أجمل».

## الدراسة والملف الشخصي

- مواد التخصص: إدارة المخزون والمخازن، إدارة المشتريات والعقود والمناقصات، إدارة النقل والشحن الدولي، مبادئ إدارة الأعمال، ومقدمة في إدارة سلاسل الإمداد.
- محاضرات أسبوعية، تقويم للاختبارات والواجبات والمشروعات، وتنبيهات تعارض المواعيد. أزرار العودة والتالي والقائمة تحفظ التنقل بين الصفحات.
- خطة مذاكرة بحسب الموعد والأولوية والوقت المتاح، مع جلسات موجهة للفهم والاسترجاع والتدريب والتقييم ومراجعات متباعدة. المؤقت يحفظ التقدم؛ يُخصم وقت المذاكرة الفعلي فقط، ولا تصبح المهمة منجزة تلقائياً عند إنهاء جلسة.
- ملاحظات المحاضرات وملخص أولي قابل للتعديل، مستخرج من النص الذي يدخله الطالب. الخطة والملخص يحتاجان مراجعة الطالب، ولا يضمنان نتيجة اختبار.
- بنك إدارة المخزون والمخازن: **٤٠ سؤالاً** من الحزمة المرفوعة، بتدريب وتصحيح فوري أو اختبار وتصحيح عند النهاية، مع حفظ المحاولة ومراجعة الأخطاء. مفاتيح الإجابات من الملف الأصلي وليست تصحيحاً جامعياً مستقلاً.
- قاموس **٥٠ مصطلحاً لوجستياً** من الصورة المرفوعة، مع الصورة الأصلية، بحث وبطاقات واختبار معاني. يوضح السياق والمصطلحات التاريخية مثل DDU.
- صورة بروفايل من الكاميرا أو الجهاز، بيانات شخصية ومهنية، وسيرة PDF حتى ٢ ميغابايت، مع التنزيل والمشاركة حيث يدعمها الجهاز والطباعة.
- ميزانية ومصروفات ومصادر دخل شهرية. الدخل المتوقع منفصل عن المبلغ المستلم؛ لا يُسجَّل استلامه إلا بالتأكيد. تغيير العملة يغير العرض فقط.

## تيتشر لوجستيك وجديد التخصص

المساعد يشرح بعبارات سعودية، ويراجع الملاحظات المسجلة والمصطلحات وبنك الأسئلة، ويقرأ جدول المحاضرات والاختبارات، ويقدم اختبارات قصيرة. يميز النص المستند إلى مصدر من الشرح أو الاستنتاج التعليمي داخل التخصص، ويرفض الأسئلة خارجه. لا توجد خدمة LLM خارجية أو مفاتيح ذكاء اصطناعي؛ المحرك محلي، ولا يدعي معرفة محاضرات لم تُضف نصوصها.

القراءة تستخدم أصوات الجهاز عبر `SpeechSynthesis` مع تفضيل `ar-SA`. الصوت واللهجة الفعليان يعتمدان على الأصوات المثبتة. الميكروفون يحتاج متصفحاً يدعم التعرف الصوتي، وإذن المستخدم وسياقاً آمناً مثل HTTPS؛ وقد يعتمد التعرف على خدمة المتصفح. الكتابة والشرح النصي متاحان عند غياب دعم الصوت. اختبارات المتصفح تحاكي واجهات الصوت، ولا تثبت جودة النطق على جهاز حقيقي.

صفحة «جديد تخصصك» تجلب RSS فعلياً، وتعرض المصدر وتاريخ النشر وآخر جلب، مع تصنيف وبحث وتخزين مؤقت عشر دقائق. المصادر الثابتة هي أخبار Google للجهات السعودية ذات الصلة وSupply Chain Dive. يلزم السماح بخروج الشبكة إلى `news.google.com` و`www.supplychaindive.com`. **البيئة السحابية الحالية تعيد 403 للمصدرين**؛ تعرض الصفحة تعذر الاتصال ولا تختلق أخباراً أو تسمي نسخة قديمة أخباراً محدثة. الأخبار مساندة للدراسة وليست إعلانات الجامعة.

## الوظائف والدورات

تضم صفحة الفرص جدارات ولينكدإن ودروب وكورسيرا، وإضافة مواقع HTTPS أخرى. جهز بياناتك، انسخها أو نزّل السيرة أو شاركها، ثم افتح الموقع وسجل الدخول وراجع الطلب وأرسله بنفسك. يمكن تسجيل حالة التقديم في مدار؛ لا تعني هذه الحالة قبول الطلب أو التحقق منه لدى الموقع.

توجد إضافة اختيارية لـ Chrome وEdge على الكمبيوتر: [دليل التثبيت والتعبئة](application-autofill/README.md). تنزل من صفحة الفرص، وتستورد ملف بيانات التقديم الذي يصدره مدار، وتعبئ الحقول الفارغة المعروفة وترفق السيرة بعد ضغط المستخدم. لا تعبئ كلمات المرور أو الموافقات ولا ترسل الطلب. على iPhone وAndroid استخدم النسخ والمشاركة والرفع اليدوي. اختُبرت وظائف الإضافة بنماذج محلية وواجهات Chrome محاكاة؛ سياسة متصفح البيئة تمنع التثبيت غير المحزم، لذا لم يُختبر التثبيت الفعلي فيه.

## التشغيل

يتطلب **Node.js 24 أو أحدث** وnpm.

```sh
npm ci
npm run owner:init
npm run dev -- --port 5173 --strictPort
```

إن تعذر استخدام مخزن npm الافتراضي:

```sh
npm --cache /workspace/.cache/npm ci --no-audit --no-fund
```

لبناء التطبيق وتشغيل خادم الإنتاج، ومنفذه الافتراضي ٤١٧٣:

```sh
npm run build
PORT=4173 npm start
```

`npm run preview` يشغل خادم Node نفسه. ملفات `dist/` وحدها تكفي لعرض الواجهة، لكن **تسجيل المالك والأخبار وحفظ نسخ الخادم تحتاج خادم Node**؛ شغله خلف HTTPS عند النشر، وحدد أصل الموقع العام الحقيقي:

```sh
MADAR_PUBLIC_ORIGIN=https://your-domain.example MADAR_SECURE_COOKIES=1 PORT=4173 npm start
```

احتفظ بمجلد `.madar/` الخاص على مساحة تخزين دائمة قابلة للكتابة لخادم التطبيق. لا تنشره أو تضفه إلى Git أو ملفات الموقع العامة.

## حساب المالك والبيانات

ينشئ `npm run owner:init` حساباً مرة واحدة باسم **`Aziiz1996`** افتراضياً، وكلمة مرور عشوائية داخل الملف الخاص `.madar/owner-credentials.txt` بصلاحية `600`. لا يطبع كلمة المرور ولا يغير الحساب عند إعادة التشغيل. يمكن تعيين اسم آخر عند الإنشاء الأول عبر `MADAR_OWNER_USERNAME`.

تخزن كلمة المرور كاشتقاق `scrypt` مع ملح، وتستخدم الجلسات رموزاً عشوائية وملف ارتباط `HttpOnly` و`SameSite=Strict`، مع تحقق المصدر وCSRF للكتابة وحد لمحاولات الدخول. الجلسة تنتهي بعد ثماني ساعات أو إعادة تشغيل الخادم. تغيير كلمة المرور من لوحة المالك يلغي الجلسات ويحذف ملف كلمة المرور الأولية. إعداد `Secure` مطلوب للنشر عبر HTTPS كما في أمر التشغيل أعلاه.

تسمح لوحة المالك بتعديل الاسم والألوان والترحيب وترتيب الصفحات وإخفائها، وإدارة المحتوى من صفحات التطبيق، وحفظ نسخة البيانات على الخادم واستعادتها **يدوياً**، وتغيير كلمة المرور. امتياز المالك يتحقق منه الخادم؛ لا ينتج من تعديل بيانات المتصفح.

بيانات الطالب اليومية محفوظة في `localStorage` لهذا المتصفح، بما فيها الصورة والسيرة. لا توجد مزامنة تلقائية بين الأجهزة. استخدم تصدير واستيراد النسخة الاحتياطية من الإعدادات، أو الحفظ والاستعادة اليدويين في لوحة المالك، وانقل النسخ الشخصية بعناية. عند بلوغ مساحة التخزين يوضح التطبيق تعذر الحفظ.

يمكن وضع نسخة صالحة خاصة في `.madar/profile.json`. لا تُحمَّل إلا **بعد دخول المالك وفي متصفح خالٍ من البيانات المحفوظة**، ولا تستبدل بيانات موجودة. مسار التحميل محمي، والمجلد مستبعد من Git ومن بناء الواجهة. استيراد نسخة أو تحميل الأمثلة من الإعدادات يستبدل البيانات بعد التأكيد. لا تحفظ كلمات مرور الجامعة أو رموز دخولها في النسخ الاحتياطية.

دخول الجامعة وجلب واجباتها وجدولها تلقائياً غير مدمجين؛ لم تُزود البيئة ببيانات دخول الجامعة. الرابط المحفوظ يفتح بوابتها فقط، والمواعيد المسجلة في مدار تحتاج مطابقتها مع إعلان الجامعة.

## التحقق

```sh
npm test
npm run build
```

تغطي الاختبارات توزيع الوقت والبيانات والتواريخ والمال، والملف والسيرة، والأسئلة والمصطلحات والمساعد، وصلاحيات المالك، وجلب الأخبار وتحليلها. الاختبارات تستخدم بيانات اصطناعية ولا تحتاج بيانات الحساب الشخصي.

لفحوص المتصفح، شغّل خادم التطوير أولاً ثم استخدم Python وPlaywright وChromium:

```sh
MADAR_BASE_URL=http://127.0.0.1:5173 npm run test:browser
python3 tests/owner_browser.py
MADAR_BASE_URL=http://127.0.0.1:5173 python3 tests/teacher_browser.py
MADAR_BASE_URL=http://127.0.0.1:5173 python3 tests/news_browser.py
python3 tests/autofill_browser.py
```

يمكن تغيير مسار Chromium عبر `MADAR_BROWSER`؛ الافتراضي `/usr/bin/chromium`. اختبار الأخبار يستخدم استجابات محلية للتحقق من الواجهة وحالات الانقطاع، ولا يعني نجاح الوصول إلى مصادر RSS الحية. دليل الإضافة يوضح حدود اختبارها.
