# مدار

تطبيق عربي لتنظيم الحياة الدراسية والمصروفات، بواجهة تدعم الهاتف والحاسوب.

## ما يمكنك فعله

- إضافة المواد والمحاضرات الأسبوعية ومراجعة تعارض المواعيد.
- إدارة الاختبارات والواجبات والمشروعات عبر قائمة وتقويم ميلادي شهري.
- توليد خطة مذاكرة للـ٢٨ يوماً القادمة بحسب الموعد والأولوية والوقت المتاح، مع استراحات بين الجلسات.
- حفظ نصوص المحاضرات واستخراج ملخصات أولية قابلة للتعديل والنسخ والتصدير.
- متابعة المصروفات والدخل والميزانية، وتسجيل مصادر دخل شهرية ومواعيدها، وتأكيد الاستلام الفعلي.
- حفظ رابط موقع الجامعة، وتصدير نسخة احتياطية واستيرادها.

## التشغيل

يتطلب Node.js 22.12+ وnpm. البيئة السحابية الحالية تستخدم Node.js 24.

```sh
npm ci
npm run dev
```

للتحقق وبناء نسخة ثابتة:

```sh
npm test
npm run build
npm run preview
```

إذا كان مجلد npm الافتراضي غير قابل للكتابة، استخدم مخزناً قابلاً للكتابة، مثل:

```sh
npm --cache /workspace/.cache/npm ci --no-audit --no-fund
```

يمكن استضافة محتويات `dist/` على استضافة مواقع ثابتة. إعداد `base: './'` يدعم التشغيل تحت مسار فرعي أيضاً.

## البيانات والتخصيص

تُحفظ البيانات في المتصفح الذي تستخدمه. لا يوجد حساب سحابي أو مزامنة بين الأجهزة؛ انقل البيانات عبر النسخة الاحتياطية من الإعدادات. تسجيل الدخول إلى الجامعة وقراءة واجباتها تلقائياً غير مدمجين في هذا الإصدار؛ رابط الجامعة يفتح موقعها مباشرة.

يمكن للبيئة الشخصية وضع نسخة احتياطية صالحة في `.madar/profile.json`. خادم التطوير يحمّلها في أول زيارة عندما لا توجد بيانات محفوظة. هذا المجلد مستبعد من Git، وبياناته لا تدخل بناء الإنتاج. عند استخدام نسخة الإنتاج، استورد النسخة الاحتياطية من الإعدادات. لا تضع كلمات مرور أو رموز دخول داخل هذا الملف.

الأمثلة التجريبية لا تُحمَّل إلا باختيارها من الإعدادات. تحميلها أو استيراد نسخة يستبدل البيانات الحالية بعد التأكيد.

## كيفية توزيع المذاكرة

تُعطى الأولوية للمواعيد الأقرب ثم للأولوية المحددة. حد الجلسة ٤٥ دقيقة، وبين الجلسات استراحة ١٠ دقائق. يلتزم المخطط بأيام المذاكرة والدقائق اليومية، ويتجنب المحاضرات والاختبارات ذات الأوقات المحددة، ولا يجدول بعد انتهاء الموعد. الدقائق اليومية هي وقت التركيز؛ الاستراحات تزيد الزمن الفعلي المنقضي.

مدة المهمة هي **الوقت المتبقي** للإنجاز. عدّلها بعد المذاكرة، أو علّم المهمة منجزة. إذا لم يكفِ الوقت، يُظهر التطبيق الدقائق غير المجدولة. الوقت غير المعروف لا يُفترض: الاختبار دون وقت يبدأ التحضير له قبل يومه؛ والمحاضرة دون نهاية تحجز بقية يومها حتى تأكيد المدة. الخطة تقديرية وتحتاج مراجعة وقت التنقل والتزاماتك الأخرى.

الملخص الأولي يستخرج جملاً من النص المدخل؛ راجعه وأكمله بمفاهيم المحاضرة وأمثلتها قبل الاعتماد عليه. لا توجد خدمة ذكاء اصطناعي أو اتصال خارجي للتلخيص.

الدخل المتوقع يظل منفصلاً عن العمليات المسجلة. لا يصبح مبلغاً مستلماً إلا عند تأكيد الاستلام. تغيير العملة يغيّر العرض فقط ولا يحوّل المبالغ.

## التحقق

اختبارات Node تغطي توزيع الوقت، المواعيد النهائية، تعارض المحاضرات والاختبارات، التواريخ والتلخيص والحسابات المالية. اختبار المتصفح يستخدم بيانات اصطناعية ويتحقق من الإنشاء والتعديل والحذف، الحفظ، النسخ الاحتياطي، ومنع تكرار استلام الدخل والتوافق مع الهاتف.

لتشغيل فحص المتصفح، شغّل خادم التطوير أولاً، ثم في جلسة أخرى:

```sh
npm run test:browser
```

يتطلب هذا الفحص Python وحزمة Playwright وChromium، المتاحة في البيئة السحابية. المسار الافتراضي للمتصفح `/usr/bin/chromium`؛ يمكن تعديله عبر `MADAR_BROWSER`. يمكن تعديل عنوان الخادم عبر `MADAR_BASE_URL` ومجلد النتائج عبر `MADAR_TEST_OUTPUT`. الفحص يستعمل سياق متصفح منفصلاً وبيانات اصطناعية.
